# First Person 3D Game

A small first-person 3D project built with Three.js and JavaScript.

## 🚧 Work in Progress

This project is still a work in progress. I'm using it as an opportunity to branch out from my usual web development projects and try my hand at something new.

## 🎮 About the Project

Most of my development experience so far has been focused on web development, building websites and applications using technologies like React, Next.js, and JavaScript. I've also started exploring game development through some 2D and 3D projects, and wanted to take things a little further.

This project is my attempt at creating a simple first-person 3D environment using Three.js. I'm starting with basic movement, camera controls, and physics, while gradually learning more about how 3D games work behind the scenes.

It's primarily a learning project, so I'll continue experimenting with new ideas and adding features as I become more comfortable with Three.js.

## ✨ Current Features

- First-person 3D environment
- Platform built with Three.js
- Mouse look and WASD movement
- Mobile touchscreen controls with a virtual joystick
- Touch-based camera controls
- Jumping and basic gravity
- Responsive controls for desktop and mobile

## 🛠️ Built With

- **Three.js** – 3D graphics and rendering
- **JavaScript** – Game logic and interactions
- **Vite** – Development server and build tool
- **HTML & CSS** – Page structure and styling

## 📚 Learning Goals

Through this project, I'm exploring things like:

- First-person camera movement and controls
- Working with 3D environments and geometry
- Understanding gravity and basic physics
- Handling keyboard, mouse, and touchscreen input
- Creating interactive environments with Three.js
- Learning more about how 3D games are structured

## 🚀 Future Improvements

I'll continue building on this project as I learn more about Three.js, experimenting with new mechanics, environments, and different ways to interact with the 3D world.
